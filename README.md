# Hello Melon Landing

Next.js App Router + TypeScript + Tailwind scaffold with `Nav + Hero` implemented from wireframe.

## Run

```bash
npm install
npm run dev
```

## Current Scope

Implemented:
- Top ribbon nav/header
- Hero section (copy, CTA, mascot slot, background slot, bottom wave)
